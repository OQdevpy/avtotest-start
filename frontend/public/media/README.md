# Rasmlar papkasi

Savol va bo'lim rasmlari shu papkaga qo'yiladi. Fayl nomlari `content.json`
dagi nomlar bilan bir xil bo'lishi kerak (masalan `questions_1752409107402_583.png`).

Demo (GitHub Pages) uchun rasmlar shu papkadan to'g'ridan-to'g'ri o'qiladi:
`https://oqdevpy.github.io/avtotest-start/media/<fayl>`.

Jami ~720 ta rasm. Firebase eksportidagi `media/` papkasini shu yerga ko'chiring.
